### Описание проекта
В рамках лабораторной работы разрабатывается Windows Forms приложение на языке C# для тренировки скоропечатания.  
Первая версия приложения позволяет пользователю ввести свою фразу и проверить скорость и точность ввода текста.  
Во второй версии приложения будет добавлена настройка уровня сложности.

### Этапы разработки
1. Создание репозитория на GitHub.  
2. Добавление файла README.md с описанием начала работы.  
3. Разработка первой версии приложения.  
4. Фиксация первой версии в локальном и удалённом репозитории.  
5. Разработка второй версии приложения.  
6. Фиксация второй версии в локальном и удалённом репозитории.  
7. Сравнение изменений между версиями.  
8. Демонстрация отката к предыдущей версии проекта.
